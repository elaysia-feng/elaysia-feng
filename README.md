## Engineering Philosophy

- **Metrics-Driven** — 压测 → 剖析 → 调优，先拿数据再定方案
- **Clear Boundaries** — 接口与契约收敛复杂度，无共享可变状态
- **Observability First** — 日志 / 指标 / Trace 起步即埋，可观测性默认开启
- **Code Hygiene** — RAII · 强类型 · 少裸指针 · 可测试性优先
